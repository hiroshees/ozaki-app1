# 共有カレンダー（Googleカレンダー風）仕様

## 目的
- 学習用。Next.js（App Router）+ Supabase + Prisma + Vercel で、エージェント駆動開発の流れを一通り経験する
- UI は Googleカレンダーを参考にするが、ロゴ・名称・アイコンなど Google のブランド要素は使わない

## 前提
- ユーザーの概念はない。ログインせずに誰でも閲覧・作成・編集・削除できる
- カレンダーは1つだけで、アクセスした全員が同じ予定を見る（共有）
- Supabase はデータベースとしてのみ使う（Auth・Storage は使わない）
- 本番は Vercel。予定の日時は Asia/Tokyo 基準で表示する

## MVP で作るもの
### 表示
- 月・週・日の表示切り替え
- 前へ / 次へ / 今日ボタン、ヘッダーに表示中の期間（例: 2026年10月）
- 表示状態は URL に持つ（例: `/?view=week&date=2026-10-17`）。リロード・共有しても同じ画面になる
- 左サイドバーにミニカレンダー（日付クリックでその日へ移動）
- 週・日表示: 0〜24時の時間グリッド、上部に終日予定の欄、現在時刻の赤線
- 月表示: 6週分のマス。1日に入りきらない予定は「他 N 件」と表示

### 予定の操作
- 作成: 「作成」ボタン、または週・日表示の空き時間クリック（クリックした時刻で30分の予定）
- 編集・削除: 予定クリックで詳細ダイアログを開き、そこから編集・削除（削除は確認あり）
- 項目: タイトル（必須・100文字以内）、開始・終了日時、終日フラグ、色（6色から選択）、メモ（1000文字以内）
- 週・日表示で予定をドラッグして時間を移動（15分単位）

## MVP で作らないもの
- ログイン、ユーザーごとのカレンダー、権限
- 繰り返し予定、通知、招待、ゲスト
- 複数カレンダー（仕事 / 個人の切り替え）
- 予定のリサイズ（ドラッグで終了時刻を伸ばす）、月表示でのドラッグ移動
- 年表示、検索

## 受け入れ条件
- [ ] 月表示で、前月・翌月にまたがる週の日付も正しく表示される（日曜始まり）
- [ ] 週表示で、時間が重なる予定は横に並び、互いに隠れない
- [ ] 日付をまたぐ予定（例: 23:00〜翌1:00）が両日に正しく表示される
- [ ] 終日予定は時間グリッドではなく上部の欄に表示され、複数日の終日予定は帯で表示される
- [ ] 開始より前の終了時刻、空のタイトルは保存できず、エラーメッセージが出る
- [ ] Vercel 上でも、日時が日本時間で表示される（9時間ずれない）
- [ ] 2つのブラウザで開き、片方で作成した予定がもう片方にリロードなしで表示される
- [ ] ブラウザから Supabase へ直接書き込みできない（書き込みはサーバー経由のみ）
- [ ] スマートフォン幅でも横スクロールなしで日表示が使える

## 既知の割り切り
- 同じ予定を同時に編集した場合は、後から保存した方が勝つ
- 誰でも削除できるため、荒らしへの対策は入力値の検証とサーバー経由の書き込みに留める
